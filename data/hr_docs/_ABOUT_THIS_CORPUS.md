# About this corpus

Every document in this folder is FICTIONAL sample data for testing a RAG system. Acme Analytics Pvt Ltd does not exist; names, numbers and policies are invented. Do not use them as HR or legal advice.

Files starting with an underscore are skipped by the ingestion pipeline.

Regenerate with `uv run python scripts/build_hr_corpus.py` (sources in scripts/hr_corpus_src/).
